# Women Safety Smart Alert System

This example demonstrates a simplified "smart alert" system for women's safety. It simulates a panic button press, which triggers a multi-step intelligent response: retrieving the user's current location, sending an emergency notification to predefined contacts, and activating a local audible alarm. This illustrates how technology can provide real-time, automated assistance in critical situations.

## Language

`python`

## How to Run

1. Save the code as `safety_alert.py`.
2. Run from your terminal: `python safety_alert.py`
3. Follow the on-screen prompts to simulate a panic event.
